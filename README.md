# ClientFlow

Modern desktop CRM application built with Python and CustomTkinter.

## Features

- Add clients
- Edit clients
- Delete clients
- Search clients
- Follow-up status system
- Dashboard statistics
- Import Excel files
- Export Excel files

## Technologies Used

- Python
- CustomTkinter
- Tkinter
- OpenPyXL
- JSON

## How To Run

```bash
pip install -r requirements.txt
python app.py
